@apply Directive Demo

The @apply directive allows you to extract common utility patterns into custom CSS classes, making your markup cleaner when you need to reuse complex button styles.

Primary Button

Multiple Buttons

The CSS

.btn-primary {
  @apply bg-blue-600 text-white font-semibold py-2 px-4 rounded-lg shadow-md transition-colors duration-200;
}

.btn-primary:hover {
  @apply bg-blue-700;
}

.btn-primary:focus {
  @apply outline-none ring-2 ring-blue-400/75;
}
